# 时间间隔计算器 (Time Interval Calculator)

一个简洁、高效、响应式的在线时间计算与累加工具。支持计算两个时间点之间的分钟数、小时数、秒数，支持跨天计算以及多时间段累加汇总。

## ✨ 功能特点

- **精确计算**：自动计算两个时间点之间的总分钟数、小时+分钟组合、总秒数及浮点小时。
- **跨天支持**：支持自动识别或手动勾选“跨天（+24小时）”计算（例如 `22:00` 到 `02:30`）。
- **多段累加**：支持添加多个时间段，并实时汇总总时长，适合工时统计、学习时长记录等。
- **快捷操作**：提供一键填充当前时间及预设示例功能。
- **响应式设计**：纯前端实现，适配桌面端与移动端，无需后端服务。

## 🚀 快速使用

### 本地运行
直接双击打开 `index.html` 即可在浏览器中使用。

### GitHub Pages 部署
1. 将本项目代码推送到您的 GitHub 仓库。
2. 进入仓库设置 **Settings** -> **Pages**。
3. Source 选择 `main` (或 `master`) 分支，Root 目录选择 `/ (root)`，点击 Save。
4. 稍等片刻即可通过 GitHub Pages 提供的链接在线访问！
